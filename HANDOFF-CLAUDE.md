## 4. Задача на доработку (приоритет)

Сайт: **https://gost.info/pntd/**

Сейчас: закрытый прототип, гостям **401**, вход через форум (`/forum2/pntd_gate.php` → progost.info). Форум часто недоступен — нужна своя авторизация.

### 4.1. Вход по email + 6-значный код

1. Пользователь вводит **email**.  
2. Если адрес **есть в allowlist** — на почту уходит **6-значный код**.  
3. Пользователь вводит код → сессия → доступ к `/pntd/`.  
4. Если адреса **нет в allowlist** — код **не** отправлять, вход запрещён.  
5. TTL кода ~10–15 мин, rate-limit на отправку, код хранить **хешем**, CSRF на формах.  
6. Сохранить текущий визуальный стиль gate (темы справа можно оставить).

### 4.2. Раздел «Администрирование»

- В интерфейсе — раздел **«Администрирование»**.  
- Пользователь **andrey** управляет списком разрешённых email (добавить / удалить).  
- Роль admin: закрепить за andrey (например email andrey / флаг в конфиге). Точный email andrey — взять из боевого конфига или уточнить у владельца (`andrzap1977@gmail.com` фигурировал в cloud run).  
- После входа по OTP andrey видит админку; обычные allowlist-пользователи — только просмотр.

### 4.3. Почта

SMTP в cloud не найден. На reg.ru часто работает PHP `mail()`. Проверьте конфиги на сервере после скачивания; при необходимости заведите `config.local.php` (в `.gitignore`) с SMTP.

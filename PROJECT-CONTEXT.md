## Когда придут файлы КП

1. Пользователь загружает файлы КП в этот чат (cloud).
2. Агент определяет организацию по содержанию/названию/указанию пользователя.
3. Берёт следующий свободный исходящий номер: **23** для «Норма софт», **80** для «Нормасофт» (увеличивать после каждого успешного создания).
4. Создаёт запись в журнале через веб UI https://gost.info/gost-documents/ или согласованный импорт в БД + `document_files` / storage.
5. Не смешивать документы двух фирм; не сбрасывать чужие номера.
6. Не коммитить пароли, FTP/MySQL credentials, ключи бэкапа в git.

# Деплой модуля «Сохранение системы»

## Статус
- Пользователь **andrey** в БД: `role = admin` (подтверждено).
- Пароль входа — у владельца / в чате агента (не хранить в git).
- Таблица `settings` создана.
- FTP с cloud-агента часто **не работает** — залить модуль нужно через FileZilla.

## Что залить (FileZilla → gost.info)

В каталог `gost-documents/public/` залейте один файл:

`install_system_backup.php`

из папки:
`gost-system-backup-module/deploy/install_system_backup.php`

или с вашего ПК, если скопируете deploy к себе.

## Установка
Откройте URL установщика с `?key=` = константа `INSTALL_KEY` из `install_system_backup.php`  
(ключ также есть в чате агента; не дублировать пароли приложения в git).

Ожидаемый ответ: `OK installed`

Затем в меню админа: **Сохранение системы**  
(`?view=system_backup`)

1. Задайте пароль архива (≥ 8 символов)
2. Нажмите «Создать запароленный ZIP»
3. Скачайте архив — в нём код + storage + database_full.sql + RESTORE.txt

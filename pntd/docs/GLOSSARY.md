# Глоссарий ПНТД

| Термин | Значение |
|--------|----------|
| **ПНТД / PNTD** | Перечень нормативно-технической документации; также бренд закрытого контура на gost.info (`P` — project · professional · protect) |
| **НТД** | Нормативно-техническая документация: стандарты, СП, ТУ, классификаторы, методические документы |
| **Карточка НТД** | Публичная запись указателя (`/nd/{id}.html`) с обозначением, статусом, атрибутами, классификаторами и связями |
| **Обозначение** | Нормативный идентификатор документа (например `ГОСТ 24297-87`, `ГОСТ Р 8.861-2013`) |
| **Статус** | Юридико-информационный статус в указателе: действует, заменён, отменён/утратил силу, принят, неизвестен |
| **ОКС** | Общероссийский классификатор стандартов (иерархия вида `03`, `03.120`, `03.120.10`) |
| **КГС** | Классификатор государственной стандартизации (буквенные разделы `А`… и группы `Т51`) |
| **ОКСТУ** | Классификатор стандартов и ТУ (часто четырёхзначные коды `0000`, `0025`; на сайте отдельно от ОКС) |
| **ГРНТИ** | Государственный рубрикатор научно-технической информации (коды вида `81.81.05`) |
| **Связь НТД** | Отношение между карточками: заменяет / заменён на / нормативная ссылка / ссылаются на документ |
| **Маркер статуса в выдаче** | Буква в поиске/связях: `Д` действует, `З` заменён, `У` утратил силу/отменён, `?` неизвестен |
| **Открытый указатель** | Публичный сайт https://www.pntd.ru/ — поиск и навигация по карточкам без авторизации |
| **Закрытый контур / gate** | Прототип https://gost.info/pntd/ — допуск через форум progost; гости получают 401 |
| **PNTD-GATE** | Обозначение страницы допуска; статус «закрытый контур» |
| **Тема UI** | Визуальная оболочка прототипа (`reglament`, `kontur`, `garant`, `wiki`, …) |
| **SKU / article / software_code** | Коды позиций каталога линейки в прототипе (поля форм price/catalog) |
| **База (base)** | Позиция каталога вида «база» с набором тарифов (`data-tariffs`, например `price_local`) |
| **ПО (software)** | Позиция каталога вида «программный продукт» |
| **Тариф** | Вариант цены для базы (ключ в карте тарифов строки комплекта) |
| **Комплект (kit / case)** | Конфигуратор набора позиций на N месяцев со скидкой при сроке ≥ 12 |
| **Цена «по запросу»** | Пустая цена в комплекте: строка не входит в сумму, помечается как open |
| **gost-documents** | Отдельное приложение учёта внутренних/исходящих документов организаций Norma Soft |
| **Метка НД** | Код вида `НД-XXXX-XXXX` в Word КП (restamp); не путать с id карточки `/nd/{id}.html` |
| **Жизненный цикл карточки** | published → replaced / cancelled / amendment; `id` URL стабилен |
| **Нумерация КП** | Счётчик исходящих/входящих/внутренних **внутри** организации в gost-documents |
| **Bounded context** | ПНТД-указатель, PNTD-линейка и gost-documents — три разных контура одной экосистемы |
